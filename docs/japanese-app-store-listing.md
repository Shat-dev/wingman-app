# Japanese App Store listing (Release D): draft

Drafted 2026-11-16 by Claude, modelled on [french-app-store-listing.md](french-app-store-listing.md). **No Japanese speaker has read any of it.** Send it to the proofreader with the review pack (`localization/ja/review/wingman-japanese-review-pack.xlsx`).

**Status:** draft only. Nothing has been entered in App Store Connect. Nothing has been rendered or uploaded.

**When it goes live:** with the Release D submission, not before. The name, subtitle, description, keywords, screenshots and "What's New" go live with a version. A Japanese page for an app that is not yet in Japanese draws one-star 「日本語に対応していません」 reviews. Promotional text can change at any time.

**Where to paste it:** App Store Connect → Wingman.
- **App Information** → the language menu, top right → add **Japanese**. The name and subtitle go here.
- **The new version** → the language menu → Japanese. The description, keywords, promotional text, What's New and screenshots go here.
- **Subscriptions** → the group → each subscription → Localization → Japanese.

A script counted the characters below, one per character whether full-width or not. Apple's limits are:

| Field | Limit |
|---|---|
| Name | 30 |
| Subtitle | 30 |
| Keywords | 100 |
| Promotional text | 170 |
| Subscription display name | 30 |
| Subscription description | 55 |
| Retention message title | 66 |
| Retention message subtitle | 144 |

**Not confirmed:** whether App Store Connect counts a Japanese character as one or two in each field. Its own live counter is the authority; if it counts two, the keyword field below is too long and must be cut.

**Tone:** polite です・ます, like the app, with no あなた. Headlines and captions are in dictionary form or end in a noun, the way the app's lesson titles are.

**Typography:** full-width 、。「」：！？ in Japanese sentences; digits, % and Latin letters half-width with no space around them. Copy the text blocks from this file and don't retype them.

## Name (30)

**Recommended:** `Wingman: 恋愛の自信と会話力` (18)

**Alternative:** `Wingman: 女性に声をかける自信` (19)

The English name is "Wingman: Dating & Confidence". The recommended name keeps that meaning: confidence and conversation in dating. The alternative says more plainly what the app teaches, as the German (*Frauen ansprechen*) and French (*Aborder une femme*) names do.

**Not checked:** what the Japanese store shows for these words, and whether another app there is already called Wingman. The French draft ran Apple's public store search for each candidate; the same search with `country=jp` should be run before choosing.

**Open points for the adviser (legal, not guessed):**

## Choices to check

These are also worth a line to the proofreader.

- **Name:** does 「恋愛の自信と会話力」 read as an app name, or is 「女性に声をかける自信」 clearer and still respectable?
- **モテる in the keywords.** It is what men type, but it leans towards the pickup tone. Keywords are not shown to users, so it is kept.
- **声かけ in the keywords** while the app avoids the word. Kept for search only.
- **The headline style** on the banners and screenshots: dictionary form (「自分から話しかける。」) rather than です・ます or the casual 〜よう. Does it read as advertising copy or as a manual?
- **「男になる」** on banner B ("Be the guy who walks over"): natural and not macho?

## Screenshots: how to make the Japanese set

These are the same steps as the other languages:
1. **Duplicate the five Figma frames** as "JA 1" to "JA 5".
2. **Replace the text layers** with the Japanese above. Japanese has no spaces, so set every line break by hand at a phrase boundary; an automatic break can split a word. The Latin display font has no Japanese glyphs, so choose a Japanese face (Hiragino Sans or Noto Sans JP at a heavy weight).
3. **Set the hand-lettered line in type or drop it.**
4. **Change the phone contents.**
   - Type the Japanese from the tables above if the phone screens are text layers.
   - Otherwise take fresh Japanese captures on the simulator. Each capture run creates a guest user in production, so it needs Arthur's OK.
5. **Export at 1284 × 2778 and upload** under the Japanese localization.

If you skip step 4, the Japanese page can launch with Japanese captions over English phone screens.

### Header and search banners (HTML)

`marketing/app-store-assets/` holds four HTML banners: `header-a`, `header-b`, `search-a` and `search-b`. Japanese copies sit next to them as new files, with the same layout and art. **They have not been rendered, looked at or uploaded**, so the sizes below are arithmetic, not something seen on screen.
- `header-a-ja.html` and `search-a-ja.html`:
  - The headline is 固まるのは、もう終わり。**自分から話しかける。** ("Stop freezing. Start talking.").
  - The line under it is 緊張がやわらぎ、会話が楽になり、本物のつながりが生まれる。
  - The labels are 頭の中 and 会話の中.
- `header-b-ja.html` and `search-b-ja.html`:
  - The headline is 自分から **声をかけに行く** 男になる。 ("Be the guy who walks over."), broken by hand into three lines.
  - The line under it is どこにいても、会話を始められる自信を。
- **What differs from the English files:**
  - The headline size is smaller (140px on header A, 200px on search B), because a Japanese character is about twice as wide as a Latin letter.
  - The letter-spacing is reset to 0 and the line height is opened up, because the English values are tuned for Latin capitals.
  - `lang="ja"` is set. The page font, Manrope, has no Japanese glyphs, so the browser falls back to the system Japanese font; pick a font on purpose before rendering.
- The phone images (`src/app-choice.png`, `src/app-courses.png`) are English app captures. A Japanese set needs Japanese captures (same guest-user caveat).
- **`render.sh` was not changed.** Its loop lists `"" -es -fr`; add `-ja` there before rendering, then check every line break by eye.
