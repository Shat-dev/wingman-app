# Wingman onboarding in French: rewrite for review (21 Nov 2026)

The first French version was a machine translation done line by line from English. Some sentences kept the English shape ("Parmi les hommes de 18 à 24 ans, 45 %…", "Ton futur toi compte sur toi"). This version is rewritten from what each screen is meant to do, not from the English sentence.

**These New lines are already in the app** (from the next build on), so this file shows exactly what users will read.

**For the reviewer:** for each **New** line, say **OK** or write how you would say it. A voice note is fine. Lines under "Kept" didn't change, so only flag them if something sounds off.

Target: French from France, also read in Belgium, Switzerland and Canada (the same text shows everywhere). Use "tu" everywhere. Screen numbers match the Spanish review screenshots. The layout is the same in every language, so the Spanish screenshots also show where each French line sits.

## Notes from a second read as a Belgian, Swiss or Québécois reader

- **"Pause déjeuner" → "pause de midi".** In Belgium, Switzerland and Québec, *déjeuner* means breakfast and lunch is *dîner*. *Pause de midi* works everywhere.
- **"Touche pour…" → "Appuie pour…".** *Touche* can also be read as the noun "key", and *appuie* is what French speakers say.
- **"Annule à tout moment" → "Résiliable à tout moment".** The command form read as if it were telling the user to cancel. *Résiliable* is the standard subscription wording.
- **Kept on purpose:** *drague* and *applis* (understood everywhere, slightly less common in Québec). I avoided *rencard* and other France-only slang.

## A question for the reviewer

**"Aborder" and "une approche".** The app uses *aborder* for the verb and *une approche* for one logged approach (for example "Noter une approche"). *Aborder une fille* sounds natural, but does *une approche* in that sense sound natural to you, or like a translation or a pickup-artist term?
