## Notes for the proofreader

- **Prices** (017a): the simulator uses the US App Store, so prices show as `$69.99` / `$14.99`. Real German users see euro prices in German format, e.g. `79,99 €`.
- **017b** is the paywall's "prices could not load" error state, a real screen users see when offline.
- **016b** is what replaces the line under the logo if the user lets go too early.
- **"Nutzer"** on the home screen is the placeholder used when the user hasn't entered a name.
- **Level 1 naming:** the level guide (6-profile…/11) says "Level 1: Soziales Üben", but everywhere else it is "Level 1: Soziales Aufwärmen". Please choose one.
- **Not shown:** only the first lesson, one Daily Practice set and one scenario are shown. The rest of the content follows the same layout. The full text of every string is in `../wingman-german-review-pack.xlsx`.
